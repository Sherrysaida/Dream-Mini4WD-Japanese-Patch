# ttimeFWD 日本語化パッチ

中国語版（繁体字）のミニ四駆レースゲーム **ttimeFWD** を日本語化する非公式パッチです。  
テキストと画面画像を差し替えるだけで、**ゲーム本体には手を入れません**。

---

## 導入方法

1. インストーラ（`ttimeFWD_日语化补丁.exe`）を実行します
2. ゲームフォルダは**自動検出**されます。見つからない場合は「参照…」で  
   `FWDsteam.exe` のあるフォルダを選んでください
3. 「日本語パッチを適用」を押せば完了です

元に戻すときは「中国語に戻す」を押すだけです。  
※ ゲームが起動している場合は適用できません。先に終了してください。

インストーラは**中国語 / 日本語の2言語UI**です。右上のボタンで切り替えられ、  
初回起動時は OS の表示言語に合わせて自動で選ばれます。

---

## 安全性

- 元ファイルは自動的に `_backup_zh_CN\` へバックアップされます（削除されません）
- 「中国語に戻す」でいつでも元通り。**復元後はオリジナルとバイト単位で一致**します
- 差し替えるのはテキストと画像のみ。`FWDsteam.exe` は変更しません

## 日本語化の範囲

| 内容               | 件数                 |
| ---------------- | ------------------ |
| 画面テキスト（text.ini） | 47                 |
| 地名               | 9                  |
| 市長のセリフ           | 20                 |
| コース名＋説明          | 50                 |
| パーツ名＋説明          | 176                |
| アイテム / 整備品       | 15                 |
| 対戦キャラ名           | 20                 |
| **合計**           | **337件（578フィールド）** |

全578フィールドで検証済み：未翻訳 0、エンコード失敗 0、文字数オーバー 0。

画面のボタン・見出し・説明文は**ビットマップに焼き込まれている**ため  
（`.IMG` は8バイトヘッダ＋16bit 5-5-5 RGB）、元の中国語を消去して日本語を描き直しています（計35枚）。  
対象はメニュー、ロード、コース選択、パーツ、整備、販売、市役所、レース画面、  
対戦相手の自己紹介パネルなど、ほぼ全画面です。

用語は `確定`→**決定**、`取消`→**中止**、`等級`→**レベル** に統一しています。  
（VS画面の該当箇所のみ幅が足りず、同義の **階級** を使用）

---

## 既知の制限

1. **オープニング／エンディング動画の字幕**は変更できません（`AWARD\*.wmv` に埋め込み）
2. **装飾的な大見出し**は中国語の原标题を残し、隣に日本語を添えています  
   （各コース名、整備センター、コース選択、メインメニューのロゴなど）
3. **「市政廳」の看板**&#x3068;**「第一戰 / 第二戰 / 第三戰」**&#x306F;中国語のままです。  
   どちらも写真背景の上に乗っているため、消去して描き直すと跡が残り、  
   残すほうが見た目がきれいです

適用後は、パーツショップの商品名と説明、コース選択、市役所の会話、対戦相手の一覧を  
中心に確認してください。

---

## 手動インストール

exe を使わない場合は、`output\patch_ja\` の中身をゲームフォルダへ上書きしてください。  
`img\` 以下のファイルは、`img\` を除いた相対パスがそのままゲーム内の配置先に対応します  
（`img\INTERFACE\*.IMG` → `ttimeFWD\INTERFACE\` など）。**事前に必ずバックアップを取ってください。**

---

## 技術情報

- 文字コードは **GBK / cp936**。ゲームが ANSI 前提のため、日本語も GBK で書き込んでいます
- 長音符 `ー`（U+30FC）は GBK では2バイト目が 0xA1 未満となり `～` に化けるため  
  `—`（U+2014）に置換。半角カタカナは全角に統一しています
- バイナリのファイルサイズは不変（objdata 19872 / remark 29160 / enemy 400 バイト）
